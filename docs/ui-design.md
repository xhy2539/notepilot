# NotePilot 界面设计

本轮将正式 React 工作台调整为简约、轻松的浅色创作空间。参考 [frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md) 的设计与视觉检查流程。

## 视觉规范

| 颜色 | 值 | 用途 |
| --- | --- | --- |
| 雾白 | #FAFAFD | 页面背景 |
| 白色 | #FFFFFF | 输入与编辑面板 |
| 浅紫 | #EEEBF8 | 作品示例与柔和强调 |
| 淡蓝 | #EAF3FB | 辅助标签与纸张示例 |
| 葡萄紫 | #6A58A6 | 主操作、选中与键盘焦点 |
| 石墨灰 | #343746 | 主要文字 |

字体采用本地打包 Noto Sans SC，400/500/600 字重；标题、正文、辅助信息分层，减少过小字号。正文与操作左对齐。主按钮保持清晰对比，浅色主要用于背景。

首页左侧输入创作意图，右侧以原创排版示例说明作品形式；示例明确标注，不声称是真实生成结果。没有使用背景渐变与循环装饰动效。连接与账号折叠，扫码登录保留在面板中。

编辑页为大画布、横向页面选择及独立编辑面板；参考与音乐使用分段页签。工作台配色与实际发布卡片配色相互独立，原有三种导出样式仍可选择。

## 响应式与交互

- 宽屏：固定侧栏，作品预览与编辑面板并排。
- 平板：作品预览在上，编辑面板在下。
- 手机：简化顶部导航，提供新建作品入口；输入字段纵向排列。
- 页面按钮有选中语义，页签有可访问名称；键盘焦点可见。
- 尊重 prefers-reduced-motion，保留保存、审核、取消与导出的原有状态保护。

## 验证

前端 TypeScript 与生产构建通过。浏览器以离线演示数据实际执行：创建、选择方向、逐页编辑、保存、切换参考/音乐、审核、下载。ZIP 包包含六张 PNG、正文、来源、音乐说明与项目 JSON。390、768、1024、1440 像素宽度未出现页面横向溢出，无浏览器脚本错误。

本轮未调用真实百炼接口或登录小红书，未在 Mac 系统实测。
