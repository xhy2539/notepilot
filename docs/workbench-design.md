# NotePilot 创作工作台设计方案

阶段：供评审的独立视觉方案，未替换 main 中的前端。
使用的 skill：https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md
已读取该 skill，按主体定位、设计规范、方案自检、实现和视觉检查的流程完成。

## 主体与任务

面向知识/工具教程创作者。主要任务是理解当前作品、切换页面、改文案、查看依据与选择配乐。主视觉直接呈现正在创作的图文，以作品本身展示产品用途。

## 轻松色调（按用户补充调整）

| Token | 色值 | 用途 |
|---|---|---|
| Surface | #FFFFFF | 工作台与图片画布 |
| Canvas | #F5F6FA | 编辑区环境，低对比背景 |
| Graphite | #202735 | 主文字，保证可读 |
| Muted | #647084 | 次级信息 |
| Action | #5E6797 | 少量主要操作与选中状态 |
| Illustration | #EEEDF8 | 浅雾紫的内容插图区 |

可选插图色为淡天空蓝 #E7EFF9、浅杏粉 #F8EEEA。由原钴蓝大面积色块改为浅色内容底与深色文字，操作色保持必要对比，避免整页发灰。

## 字体与结构

中文使用 Mac 的 PingFang SC，西文使用系统/Helvetica Neue，正文13–16px，工作台标题23px，作品标题33px。桌面横向排布为窄工具栏、主画布与295px编辑面板；小屏堆叠，保留主要操作。

画布居中、文字左对齐。页面缩略图用于真实的多页导航，不以编号装饰无顺序内容。设置与登录状态收进设置入口；当前稿件相关操作留在标题旁。编辑、参考、音乐使用同一面板的页签，避免永久堆叠多个表单区域。

## 自检与取舍

去掉之前的大口号、装饰星形、密集状态横条、小字号表单和大片薄荷背景。保留一处具有记忆点的作品排版，其他界面安静地服务编辑任务。预览仅有示例内容，不模拟已取得的热门指标或已连接的服务。

此方案还未替换生产 UI，也未更改后端导出模板。评审后需要同时修改前端作品预览和 PNG 排版，避免所见与导出不一致。

## 检查

已检查浏览器运行错误、标题实时预览、页签、页码切换及移动端排版。方案中保存/审核/重画按钮只提供交互说明，不调用 API，也不声称真实保存或生图。主分支的百炼、扫码、任务和导出功能不受本分支影响。
